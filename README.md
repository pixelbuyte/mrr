# Daily Dashboard

A beautiful, personal daily dashboard built with Next.js, Tailwind CSS, and TypeScript. All data is stored locally in your browser — no accounts, no tracking, just your personal command center.

## Features

- **Live Clock & Greeting** — Real-time clock with contextual greeting based on time of day
- **Weather Widget** — Current weather conditions at a glance
- **Today's Focus** — Set your #1 priority for the day
- **Pomodoro Timer** — Built-in focus timer with work/break modes and session tracking
- **To-Do List** — Add, complete, and delete tasks with a visual progress bar
- **Habit Tracker** — Track daily habits with streak counting
- **Quick Notes** — Jot down thoughts with auto-save
- **Quick Links / Bookmarks** — Customizable bookmarks grid with color coding
- **Mood Tracker** — Log your daily mood with a 7-day history view
- **Quote of the Day** — Daily inspirational quote rotation
- **Dark/Light Mode** — Toggle between themes with system preference detection

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [Tailwind CSS](https://tailwindcss.com) v4
- [TypeScript](https://www.typescriptlang.org)
- [Lucide Icons](https://lucide.dev)
- [date-fns](https://date-fns.org)
- [Framer Motion](https://www.framer.com/motion)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Deploy instantly with [Vercel](https://vercel.com):

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/pixelbuyte/cursor-daily-dashboard)

Or build for production:

```bash
npm run build
npm start
```
