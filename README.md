# Personal Daily Dashboard

A polished personal dashboard for planning the day, tracking habits, setting a focus block, checking mood, and capturing notes. Built with React and Vite for a fast static deployment on Vercel.

## Features

- Personalized greeting, editable name, mantra, and live clock
- Daily progress score across priorities and habits
- Add, complete, and remove today's priorities
- Habit streak toggles with quick visual feedback
- Focus session length picker
- Mood check-in and daily notes
- Local browser persistence with `localStorage`
- Responsive glassmorphism UI for desktop and mobile

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated `dist/` folder can be deployed directly to Vercel.
