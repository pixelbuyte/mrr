# Cursor Daily Dashboard

A polished, personal-use daily dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Focus board with quick-add priorities
- Habit streak tracking
- Wellness sliders for sleep, hydration, movement, mood, and energy
- Built-in focus timer with presets
- Daily intention and evening journal
- Weekly momentum bars and monthly calendar
- Live local weather using browser geolocation and Open-Meteo
- Local-first persistence with browser storage

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

This app is ready for Vercel deployment as a standard Next.js project.

```bash
npm install -g vercel
vercel
```

For production:

```bash
vercel --prod
```
